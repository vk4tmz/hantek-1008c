# F6 reproducibility experiment

Sequence: control -> F6 -> F6 -> F6 -> control.

Purpose: determine whether the structured raw excursion observed in the first
F6 A/B capture is deterministic and causally associated with F6.

All other variables remain fixed: CH1 only, A2=03, A3=0F, onboard 1 kHz nominal
2 Vpp square wave.

Compare each run for:
- raw min/max/mode/mean/stddev;
- abnormal low-valued runs near ~1730-1750;
- location and duration of any anomaly;
- square-wave edge spacing and recovered sample rate;
- whether controls remain clean.
